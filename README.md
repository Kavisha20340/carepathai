# Welcome to CarePathAI

CarePathAI is a multilingual, voice-first AI healthcare navigator for India. It listens to a patient's symptoms, asks adaptive follow-up questions, safely identifies the appropriate level and type of care, and connects the patient with verified nearby healthcare providers.

This documentation provides a comprehensive overview of the CarePathAI project, including its architecture, backend and frontend implementation, deployment guide, and contribution guidelines.
